

O objetivo do projeto é aprofundar os conhecimentos em javascript, conhecendo sua sintaxe, funções, variaveis com o finalidade de se tornar a minha linguagem principal. 

Ainda falta entender boa parte do script do js. compreender o algoritmo linha por linha admito que ainda tenho dificuldades, porem interpretar o algoritmo como um todo. 

Um aspecto que preciso compreender é como as tarefas ficam de fato armazenadas sem perder o que foi escrito. No inicio achei que so armazenava os dados em um slot na memoria RAM, imaginava que quando fechasse a IDE a lista desaparecia porem estava errado, quero compreender isso. 

A lista de tarefas ter continuado guardada mesmo fechando a IDE e abrindo o projeto quebrou minha espectativa pois o diferencial que faria com esse "to do list" seria, teoricamente, usar o node.js com o modulo marked, para salvar as listas, convertendo o que estiver em <ul><li> para markdown.
